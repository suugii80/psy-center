# Сэтгэл зүйн цахим үйлчилгээ (засварласан хувилбар)

## Хавтасны бүтэц
```
psy-center/
├── server.py
└── public/
    ├── index.html
    └── admin.html
```

## Ажиллуулах (Python 3.8+, pip хэрэггүй)
- Компьютер/Termux: `ADMIN_TOKEN=өөрийнНууцКод python server.py`
- Pydroid 3: server.py-г нээж, дээд талын цэсний "Environment variables"-д ADMIN_TOKEN нэмээд ▶ дарна
  (эсвэл server.py-ийн дээд талд `os.environ.setdefault("ADMIN_TOKEN", "өөрийнНууцКод")` мөр нэмнэ)
- Сайт: http://localhost:8000 — сэтгэл зүйч: http://localhost:8000/psychologist-admin

## Юу засагдсан
- Оноо, үр дүнг СЕРВЕР тооцно; төлбөр батлагдсаны дараа л хэрэглэгчид өгнө
- Жинхэнэ төлбөрийн урсгал (demo, эсвэл QPay): сервер нэхэмжлэх үүсгэж, төлбөрийг өөрөө шалгана
- Урьдчилсан "Үгүй" сонголт авсан тул бүх асуултад заавал хариулна
- Зөвшөөрлийн тэмдэглэгээ, "онош биш" тайлбар нэмсэн
- Цаг захиалга, сорилын өгөгдөл data.sqlite3 файлд хадгалагдана
- Админ хуудас нууц кодтой, нийтийн цэснээс авсан
- Хэрэглэгчийн текстийг innerHTML-ээр оруулахаа больсон

## Танаас шаардлагатай зүйл
1. `server.py` дээрх `BANDS` (онооны зэрэглэл) нь сорилын эх сурвалжтай таарч байгааг шалгана
2. Яаралтай тусламжийн дугаараа баталгаажуулж `EMERGENCY_TEXT` орчны хувьсагчаар өгнө
3. Жинхэнэ төлбөр авахдаа: `PAYMENT_PROVIDER=qpay QPAY_USERNAME=... QPAY_PASSWORD=... QPAY_INVOICE_CODE=... PUBLIC_URL=https://...`
4. Нийтэд гаргахдаа заавал HTTPS (жишээ нь Caddy/nginx ард) байх ёстой. data.sqlite3-г нөөцөлж, хамгаална.
