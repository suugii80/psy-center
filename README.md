# Сэтгэл зүйн цахим үйлчилгээ

## Хавтасны бүтэц
```
psy-center/
├── server.py
├── data.sqlite3      (автоматаар үүснэ — нөөцөлнө)
├── files/            (автоматаар үүснэ — борлуулах файлууд, public-аас тусдаа)
└── public/
    ├── index.html
    └── admin.html
```

## Ажиллуулах (Python 3.8+, pip хэрэггүй)
```
cd D:\psy-center
python server.py --add-user          (нэг удаа: сэтгэл зүйчийн нэр, нууц үг)
$env:PAYMENT_PROVIDER="manual"       (дансны шилжүүлэг; PowerShell)
python server.py
```
Сайт: http://localhost:8000 · Сэтгэл зүйч: http://localhost:8000/psychologist-admin

## Самбараас (код засахгүйгээр) удирдах зүйлс
- **Мэдээ, нийтлэл**, **Сорил** (асуулт, оноо, үнэ, зэрэглэл)
- **Бүтээгдэхүүн**: зөвлөгөөний багц, сургалт, үнэлгээ, судалгаа, бэлэн ppt/PDF. Үнэ 0 бол "Үнийн санал авах" хүсэлт. Файл оруулсан бол төлбөр баталгаажсаны дараа л татагдана.
- **Захиалга**: худалдан авалт ба үнийн саналын хүсэлтүүд (баталгаажуулах, "Дууссан" гэж тэмдэглэх)
- **Орон нутгийн зар**: иргэдийн оруулсан зарыг ШАЛГАЖ "Нийтлэх"/"Татгалзах". **Зарын захиалга**: худалдан авагчийн захиалга (худалдагчтай шууд тооцно, сайт төлбөр авахгүй).
- **Цэс**: дээд цэсийн холбоос нэмэх, нэр солих, дараалал өөрчлөх, нуух

## Амьсгалын дасгал ба дуугаар унших
- Нүүр хуудасны "🌿 Амьсгалын дасгал (дуутай)": давхар амьсгал (cyclic sighing, Balban нар 2023, Cell Reports Medicine) — дугуй томорч жижгэрнэ, хөгжмийн дохио, дуугаар зааварчилгаа, 1/3/5 минутын хугацаа. Секундын хэмнэл судалгаанд заагаагүй тул жишээ утга. Эх сурвалж, анхааруулга цонхонд бий.
- Хэсэг бүрийн гарчиг дор "🔊 Сонсох", мөн "Бүх цэсийг дуугаар сонсох", нийтлэл дотор "🔊 Сонсох" товч байна. Хөтчийн дууны синтезийг (Web Speech) ашиглана, сервер/түлхүүр хэрэггүй.
- АНХААР: монгол хэлний дуу төхөөрөмж бүрд байдаггүй. Windows дээр Microsoft Edge (Mongolian дуутай), Android дээр Google дууны тохиргоо ажиллах магадлалтай. Дуу олдохгүй бол сайт тайлбар гаргаж, дасгал нь зөвхөн хөгжмийн дохио, дүрсээр ажиллана. Найдвартай байлгахыг хүсвэл өөрийн дуугаар бичсэн аудио файл (mp3) нэмж болно.

## AI туслах (сайтын лавлах чат, заавал биш)
Нүүр хуудасны баруун доод буланд "💬 Туслах" товч гарна. Үйлчилгээ, цаг захиалга, төлбөрийн заавар хэлнэ; онош тавихгүй, зөвлөгөө өгөхгүй. Өөрийгөө хорлох утгатай үг бичвэл гадаад AI руу огт илгээлгүй шууд яаралтай тусламжийн мэдээлэл өгнө. Түлхүүр тохируулаагүй бол товч огт гарахгүй.

Үнэгүй түвшинтэй провайдер сонгож, түлхүүр (API key) авна, дараа нь (PowerShell):
```
# Google Gemini (aistudio.google.com дээрээс түлхүүр)
$env:AI_PROVIDER="gemini"; $env:AI_API_KEY="түлхүүр"; $env:AI_MODEL="<провайдерын сайтад харагдах одоогийн загварын нэр>"
# Groq, OpenRouter, Ollama гэх мэт OpenAI-тэй нийцтэй
$env:AI_PROVIDER="openai"; $env:AI_API_KEY="түлхүүр"; $env:AI_MODEL="<загварын нэр>"; $env:AI_BASE="https://api.groq.com/openai/v1"
```
- Загварын нэр, үнэгүй хязгаар өөрчлөгддөг тул провайдерын сайтаас шалгана. `AI_DAILY_CAP` (анхдагч 300) нь өдрийн хариултын дээд тоо.
- АНХААР: үнэгүй түвшинд хэрэглэгчийн бичсэн текстийг провайдер хадгалах/сургалтад ашиглаж болно. Тиймээс туслахад хувийн мэдээлэл бичихгүй гэж сайт сануулсан. Гэрээ, нууцлалын текстэд "лавлах чат гуравдагч провайдер ашигладаг" гэж нэмнэ. Сорилын хариу, захиалгын мэдээлэл AI руу огт явахгүй.

## QR код
- Самбарын Сорил, Бүтээгдэхүүн, Мэдээ, Орон нутгийн зар бүрийн хажууд "QR" товч байна. Шинээр нэмэх бүрд QR автоматаар гарна (PNG татах, хэвлэх, холбоос хуулах).
- QR уншуулахад тухайн сорил/бүтээгдэхүүн/нийтлэл шууд нээгдэнэ. Ноорог төлөвтэй зүйл нийтэлсний дараа л нээгдэнэ.
- QR доторх хаягийг самбар дээрх "Сайтын хаяг" талбарт өөрчилнө. localhost утаснаас ажиллахгүй — интернэт хаяг эсвэл ижил Wi-Fi дээрх компьютерийн хаяг (http://192.168.x.x:8000) бичнэ.

## Орон нутгийн зах (иргэд өөрөө зарлана)
- Зарлагч нэвтрэлгүй зар оруулна → таны самбарт "хянах" төлөвтэй орно → та нийтэлнэ. Зарлагч зарын кодоор захиалгаа харж, зараа устгана.
- Спамаас: IP тутамд цагт 5 зар, 10 захиалга. Зургийг зөвхөн JPG/PNG (600KB) хүлээн авна.
- Хуулийн анхаарах: зуучлагч платформ ажиллуулахад татвар, хэрэглэгчийн эрхийн хууль, хувийн мэдээллийн (зарлагчийн утас) зөвшөөрлийг хуульчтай тулгана.

## Анхаарах
- Анхны каталогийн бүх үнэ 0 (хүсэлтээр). Өөрийн үнээ самбараас тохируулна. Бэлэн материалууд ноорог төлөвтэй — ӨӨРИЙН бэлтгэсэн файлыг оруулж байж нийтэлнэ.
- Гэрээний текст нь ноорог. Хуульчаар шалгуулна. Цээжлэн/хуулбарласан материал борлуулахгүй.
- Сорилын онооны зэрэглэлийг эх сурвалжтай тулгаж баталгаажуулна. `EMERGENCY_TEXT`-д өөрийн баталгаажуулсан яаралтай тусламжийн дугаарыг өгнө.
- Нийтэд гаргахдаа заавал HTTPS + `COOKIE_SECURE=1`. `data.sqlite3`, `files/`-ийг нөөцөлнө.
- Жинхэнэ QPay: `PAYMENT_PROVIDER=qpay QPAY_USERNAME=... QPAY_PASSWORD=... QPAY_INVOICE_CODE=... PUBLIC_URL=https://...` (туршаагүй).
