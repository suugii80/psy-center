# Сэтгэл зүйн цахим үйлчилгээ

## Хавтасны бүтэц
```
psy-center/
├── server.py
├── data.sqlite3      (автоматаар үүснэ — нөөцөлнө)
├── files/            (автоматаар үүснэ — борлуулах файлууд, public-аас тусдаа)
└── public/
    ├── index.html
    └── admin.html
```

## Ажиллуулах (Python 3.8+, pip хэрэггүй)
```
cd D:\psy-center
python server.py --add-user          (нэг удаа: сэтгэл зүйчийн нэр, нууц үг)
$env:PAYMENT_PROVIDER="manual"       (дансны шилжүүлэг; PowerShell)
python server.py
```
Сайт: http://localhost:8000 · Сэтгэл зүйч: http://localhost:8000/psychologist-admin

## Самбараас (код засахгүйгээр) удирдах зүйлс
- **Мэдээ, нийтлэл**, **Сорил** (асуулт, оноо, үнэ, зэрэглэл)
- **Бүтээгдэхүүн**: зөвлөгөөний багц, сургалт, үнэлгээ, судалгаа, бэлэн ppt/PDF. Үнэ 0 бол "Үнийн санал авах" хүсэлт. Файл оруулсан бол төлбөр баталгаажсаны дараа л татагдана.
- **Захиалга**: худалдан авалт ба үнийн саналын хүсэлтүүд (баталгаажуулах, "Дууссан" гэж тэмдэглэх)
- **Орон нутгийн зар**: иргэдийн оруулсан зарыг ШАЛГАЖ "Нийтлэх"/"Татгалзах". **Зарын захиалга**: худалдан авагчийн захиалга (худалдагчтай шууд тооцно, сайт төлбөр авахгүй).
- **Цэс**: дээд цэсийн холбоос нэмэх, нэр солих, дараалал өөрчлөх, нуух

## Орон нутгийн зах (иргэд өөрөө зарлана)
- Зарлагч нэвтрэлгүй зар оруулна → таны самбарт "хянах" төлөвтэй орно → та нийтэлнэ. Зарлагч зарын кодоор захиалгаа харж, зараа устгана.
- Спамаас: IP тутамд цагт 5 зар, 10 захиалга. Зургийг зөвхөн JPG/PNG (600KB) хүлээн авна.
- Хуулийн анхаарах: зуучлагч платформ ажиллуулахад татвар, хэрэглэгчийн эрхийн хууль, хувийн мэдээллийн (зарлагчийн утас) зөвшөөрлийг хуульчтай тулгана.

## Анхаарах
- Анхны каталогийн бүх үнэ 0 (хүсэлтээр). Өөрийн үнээ самбараас тохируулна. Бэлэн материалууд ноорог төлөвтэй — ӨӨРИЙН бэлтгэсэн файлыг оруулж байж нийтэлнэ.
- Гэрээний текст нь ноорог. Хуульчаар шалгуулна. Цээжлэн/хуулбарласан материал борлуулахгүй.
- Сорилын онооны зэрэглэлийг эх сурвалжтай тулгаж баталгаажуулна. `EMERGENCY_TEXT`-д өөрийн баталгаажуулсан яаралтай тусламжийн дугаарыг өгнө.
- Нийтэд гаргахдаа заавал HTTPS + `COOKIE_SECURE=1`. `data.sqlite3`, `files/`-ийг нөөцөлнө.
- Жинхэнэ QPay: `PAYMENT_PROVIDER=qpay QPAY_USERNAME=... QPAY_PASSWORD=... QPAY_INVOICE_CODE=... PUBLIC_URL=https://...` (туршаагүй).
